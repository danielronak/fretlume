Fretlume

A free, offline app that draws chords, scales, triads and tabs on your real guitar through any camera. It matches the reference app feature for feature, then goes further: it listens to your playing, watches your fretting hand, teaches a full course and adapts to you.

Nothing is built yet. This page is the plan a coding agent follows from an empty repository to version 1.0. “Fretlume” is a working name.

Same as the reference app, and what is added

Matched (phases 0–5)

  • Live overlay on the real neck, lock and re-lock, flip strings
  • Library of chords, scales, triads and keys with search
  • CAGED shapes and positions, colour by shape or note
  • Notes, intervals or finger labels
  • Custom practice runs with auto-advance and loop
  • Chromatic tuner with reference tones
  • Tab editor, import, play-along on the neck
  • Left-handed mode, local data, backup and restore

Added (phases 6–12)

  • Listens and grades; the reference app says it does not
  • Names the muted or wrong string
  • Sees fingers and corrects placement
  • Structured course with mastery gates
  • Daily plan sized to your time, spaced review, adaptive tempo
  • Backing band and scale guidance over chord changes
  • Runs on phones, tablets and any desktop, about 40 MB
  • Free, no account, open source

What was tested today

Four spikes ran in the cloud build container before the plan was written. Their results decided the architecture.

QuestionResult
Can the agent test camera and microphone code with no person present?Yes. A headless browser took 1280×720 frames from a video file and heard a 110 Hz tone from an audio file as 110.4 Hz. Hand tracking ran inside it.
Can the overlay stay on the neck without machine learning?Yes. A classical alignment prototype reached a median worst-case error of 0.017 of a fret along the neck and 0.08 of a string spacing across it, 100% of the time, when started within about 2 pixels of the truth. That is the frame-to-frame case.
How rough can the first guess be?Not very. Success fell to 78–85% at 5 pixels of starting error and 50–60% at 8 pixels. So the first lock needs help: four taps with a magnifier, then a small detector plus a multi-start search.
Can a detector be trained here with no graphics card?Yes. A one-million-parameter network trained at 85 images per second on four processor cores, about 300,000 images an hour.

One finding worth knowing

Fret spacing is self-similar: shift every fret by one and the wire pattern looks the same from a camera. Wires alone can never tell fret 3 from fret 4. The lock is therefore anchored on the nut and inlays, shows fret numbers on your neck for you to confirm, and offers a one-tap shift.

Synthetic test images were crude and no real guitar has been tested yet. Real-guitar accuracy is the largest open risk, which is why the four-tap manual lock ships first and always remains available.

Key decisions

  • An installable web app. It costs nothing to distribute, works offline after the first visit, runs on every system, and can be built and tested entirely in the cloud. Native Mac and iOS builds cannot be made there.
  • Lock, then track. Tracking is classical image alignment. A neural network is used only to find the neck at lock time, where a manual fallback exists.
  • Generated training data only. No public dataset has fret positions, and you should not label images.
  • Check what should sound. The app knows the expected notes, so it verifies them instead of transcribing blindly. No trained audio model is needed.
  • Nothing leaves the device. An automated test fails the build if the app makes any network request while running.
  • Original product. Its own name, look, wording and content; public-domain songs or your own imported tabs.

What you do

  1. Create an empty GitHub repository once and tell the agent its name.
  2. Approve network or environment prompts when they appear. Each is one click.
  3. Possibly one settings click to switch on GitHub Pages.
  4. At the six “you test” releases, play for ten minutes, press Export diagnostics and drop the file into the chat. Optional but valuable.
  5. Decide the name, the licence and priorities when asked.

No coding, labelling, training or data preparation.
